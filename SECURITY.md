# NetCoin Security Policy

NetCoin is experimental testnet software. It is educational code, not hardened production cryptocurrency infrastructure.

Please do not publicly disclose serious security bugs before maintainers have a chance to review and fix them.

Report security issues by email to:

netcoin2026@gmail.com

(You may also use GitHub's private "Report a vulnerability" advisory feature on the
repository once it is public.)

Include:

- NetCoin version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Logs or screenshots if useful

Do not include private keys, seed phrases, API tokens, or other secrets in reports.
