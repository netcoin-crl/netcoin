# Code of Conduct

NetCoin is a small educational project. We want a welcoming, harassment-free
experience for everyone participating — testers, node runners, miners, and
contributors.

## Our standards

Examples of behavior that helps the community:

- Being respectful and patient, especially with newcomers.
- Giving and gracefully accepting constructive feedback.
- Focusing on what is best for the project and the people in it.

Unacceptable behavior includes:

- Harassment, insults, or discriminatory comments.
- Personal or political attacks.
- Publishing others' private information without permission.
- Encouraging others to treat NetCoin as real-money or investment software — it is
  an educational testnet with no real-money value.

## Scope

This applies in all project spaces (the repository, issues, pull requests, and
discussions) and when representing the project in public spaces.

## Enforcement

Report unacceptable behavior to the maintainers via the contact in
[SECURITY.md](SECURITY.md) (or a GitHub private advisory for sensitive reports).
Maintainers may remove, edit, or reject contributions and comments that violate
this Code of Conduct, and may ban repeat offenders.

This is a lightweight adaptation in the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
