  4. Verify it in the explorer.
  5. Run your own node when ready.

Wallet

A wallet controls keys and signs payments. Do not share private keys or recovery phrases.

Node

A node validates and relays chain data. A public seed is a public node that helps others connect.

Mining

Mining tries to create blocks. Testnet mining is for learning and has no real-money value.

Merchant

Merchant tools help create invoices, checkout flows, receipts, webhooks, and CSV reports.
