Beginner path

  1. Open Wallet and create a testnet wallet.
  2. Use Faucet to request test coins.
  3. Send a small payment to yourself.
  4. Verify it in Explorer.

Reliability tools

  • Use /health or /status-lite for fast node checks.
  • Use mempool-info --summary to inspect pending transaction load.
  • Operators can clear only unconfirmed mempool transactions with mempool-clear.
  • Wallet sends now pre-check spendable balance, input count, and transaction weight.

Large-send safety

Send smaller test amounts first. Oversized transactions are rejected before broadcast so they do not make wallet, explorer, or mining feel stuck.

Download / install

Install steps (Mac, Linux, and Windows PowerShell) live on Download so there is one copy to keep current.

Open Download

Run local wallet

python -m netcoin web --node http://18.220.89.128/api --faucet https://faucet.netcoin.online

Use https://api.netcoin.online/api when your network allows the api.netcoin.online domain. Use the direct-IP API if Charter/CUJO or router security blocks the domain.

Run a node

python -m netcoin --data ~/.netcoin-testnet node --peer https://api.netcoin.online/api

Mine one block

python -m netcoin wallet-new --out my-wallet.json --mnemonic
python -m netcoin miner --node http://18.220.89.128/api --wallet my-wallet.json --blocks 1 --sync-after

Default mining pays the wallet legacy address unless you choose another address type.

Reward schedule

NetCoin starts at 50 NET per block and reduces the reward by 10% every 265,000 blocks: 50, 45, 40.5, 36.45, and so on. The live testnet upgrade activates at height 4,200 so already-mined blocks remain valid.

Become a public seed

  • Use a reliable machine with a stable public IP.
  • Forward/open port 28444.
  • Run the node with --host 0.0.0.0 --port 28444.
  • Share your URL only after it stays synced.

Address types

Legacy, p2sh-segwit, segwit, and taproot are different receiving addresses from the same wallet/private key. Coins mined with the default miner command appear under the legacy address.

Safety

Never share seed phrases or private keys. Testnet NET has no real-money value.

NetCoin is public testnet/demo software. Never share private keys or seed phrases.
