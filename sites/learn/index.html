Beginner path

  1. Open Wallet and create a testnet wallet.
  2. Use Faucet to request test coins.
  3. Send a small payment to yourself.
  4. Verify it in Explorer.

Download / install

git clone https://github.com/netcoin-crl/netcoin.git
cd netcoin
python -m venv .venv
source .venv/bin/activate
pip install -e .

Windows users can use PowerShell with .venv\Scripts\Activate.ps1.

Run local wallet

python -m netcoin web --node https://api.netcoin.online/api --faucet https://faucet.netcoin.online

Run a node

python -m netcoin --data ~/.netcoin-testnet node --peer https://api.netcoin.online/api

Mine

python -m netcoin mine --help

Become a public seed

  • Use a reliable machine with a stable public IP.
  • Forward/open port 28444.
  • Run the node with --host 0.0.0.0 --port 28444.
  • Share your URL only after it stays synced.

Safety

Never share seed phrases or private keys. Testnet NET has no real-money value.

NetCoin is public testnet/demo software. Never share private keys or seed phrases.
