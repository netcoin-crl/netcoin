NIPs

Governance and treasury belong together.

Use this hub for NetCoin Improvement Proposals, voting, public roadmap decisions, and treasury transparency.

Proposal flow

  1. Discuss an idea in Community.
  2. Draft a NIP proposal.
  3. Vote or gather feedback.
  4. Link approved spending to treasury records.

NIPs

NIP means NetCoin Improvement Proposal. Use it for protocol, wallet, website, security, and network changes.

Treasury

Treasury addresses, spending reports, and payout notes should be public and tied to proposals.

Roadmap

Accepted proposals should become roadmap milestones with status and accountability.

Treasury transparency

Treasury belongs with Governance because spending should connect to public proposals, voting, roadmap priorities, and receipts.

NIP flow

  1. Discuss idea in Community.
  2. Submit a NetCoin Improvement Proposal.
  3. Review security and testnet impact.
  4. Vote or accept after review.
  5. Link any treasury payout to the proposal.

Spending report template

Proposal: NIP-0001
Recipient: address or vendor
Amount: testnet/demo only
Reason: hosting, audit, bounty, docs
Receipt: public link

NetCoin is public testnet/demo software. Never share private keys or seed phrases.
