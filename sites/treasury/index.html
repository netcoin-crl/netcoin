Transparency checklist

  • Public address or no treasury at all.
  • Proposal before spending.
  • Manual payout review before signing.
  • Explorer link after broadcast.
  • Security note for any custody change.

Current stance

NetCoin should keep treasury behavior minimal while the project is public-testnet software. App-layer payout plans exist, but hot-wallet auto-broadcast should remain disabled without a separate key-management review.

Where records go

Governance should hold proposals and approved plans. Explorer should verify transactions. Security should document custody assumptions and incident response.

This treasury subdomain stays online for old links, but active treasury transparency belongs under Governance.
