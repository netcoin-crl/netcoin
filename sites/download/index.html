Install NetCoin from GitHub.

The direct install checklist — just the commands.

GitHub repoBeginner guide

Mac / Linux

git clone https://github.com/netcoin-crl/netcoin.git
cd netcoin
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .

Windows PowerShell

git clone https://github.com/netcoin-crl/netcoin.git
cd netcoin
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .

Mine until stopped

python -m netcoin wallet-new --out my-wallet.json --mnemonic
python -m netcoin miner --node http://18.220.89.128/api --wallet my-wallet.json --blocks 0 --sync-after

Press Ctrl-C to stop mining. Use --blocks 100 if you want a fixed amount.

Check public seeds

python tools/check_public_network.py

This is read-only and needs no wallet or SSH key.

Use https://api.netcoin.online/api when available; use http://18.220.89.128/api if the domain is blocked on your network.
