### Recent UI updates - Local browser wallet now defaults to the HTTPS public API proxy to avoid home-network blocks on custom ports. - Merchant site now has a clearer invoice/POS workflow, integration cards, and invoice table. - Community site now includes local discussion drafts and improvement ideas so testers can organize feedback before a hosted forum is connected.
