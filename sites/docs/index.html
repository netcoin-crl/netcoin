Why this changed

NetCoin groups related tools together so new users are not overwhelmed, while curious users can still find advanced areas through More and site mode.

Reliability tools

  • Use /health or /status-lite for fast node checks.
  • Use mempool-info --summary to inspect pending transaction load.
  • Operators can clear only unconfirmed mempool transactions with mempool-clear.
  • Wallet sends now pre-check spendable balance, input count, and transaction weight.

Large-send safety

Send smaller test amounts first. Oversized transactions are rejected before broadcast so they do not make wallet, explorer, or mining feel stuck.

GitHub quickstart

git clone https://github.com/netcoin-crl/netcoin.git
cd netcoin
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .

Local wallet / miner node

python -m netcoin web --node http://18.220.89.128/api --faucet https://faucet.netcoin.online
python -m netcoin miner --node http://18.220.89.128/api --wallet my-wallet.json --blocks 1 --sync-after

Use https://api.netcoin.online/api when your network allows the public API domain.

Reward schedule

Starting subsidy is 50 NET. Every 210,000 blocks the reward decreases by 20%: 50 → 40 → 32 → 25.6 NET. Live testnet activation is height 4,200 to preserve existing blocks.
