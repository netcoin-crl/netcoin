What success looks like

  • Node API returns a height and tip hash.
  • Wallet opens against the local node URL.
  • Faucet status returns a testnet-only state.
  • Explorer shows mempool and latest block information.

Install locally

python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -e .

Run the localnet harness

PYTHONPATH=. python3 tools/run_localnet.py --nodes 3 --bootstrap-blocks 101 --topology line

Start one local node

python3 -m netcoin --data ~/.netcoin-local node --host 127.0.0.1 --port 28444

Open local wallet

python3 -m netcoin web --node http://127.0.0.1:28444 --faucet http://127.0.0.1:8000/api

Create wallet and mine

python3 -m netcoin wallet-new --out local-wallet.json --mnemonic
python3 -m netcoin miner --node http://127.0.0.1:28444 --wallet local-wallet.json --blocks 1 --sync-after

Verify from CLI

curl http://127.0.0.1:28444/health
curl http://127.0.0.1:28444/info
python3 -m netcoin mempool-info --node http://127.0.0.1:28444 --summary

Not a mainnet launch page
