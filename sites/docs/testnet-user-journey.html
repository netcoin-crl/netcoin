Safety first

NetCoin is public testnet software. Testnet NET has no real-money value. Never share seed phrases, private keys, or screenshots containing full recovery words.

wallet -> faucet -> explorer -> status

First-time tester checklist

Record friction with device, browser, URL, expected result, and actual result.

  1. Create wallet. Open Wallet, create a fresh testnet wallet, and store the recovery phrase offline.
  2. Copy receive address. Open Receive and copy one address from the wallet.
  3. Claim faucet NET. Paste the address into Faucet and complete the challenge if one is enabled.
  4. Verify in Explorer. Search the address or transaction ID and confirm the transaction is pending or confirmed.
  5. Send a tiny payment. Use Wallet Send and confirm the review screen before broadcast.
  6. Lock and unlock. Lock the wallet, unlock the saved vault, and verify the dashboard returns.
  7. Check Status. If anything is stuck, check height, mempool depth, peer count, and uptime.

Success signals

  • Wallet shows the prominent testnet pill.
  • Faucet accepts the request or clearly explains cooldown.
  • Explorer shows pending or confirmed activity.
  • Status shows height, mempool depth, peers, and uptime.

Report format

  • Device and browser.
  • URL and action taken.
  • Expected versus actual result.
  • Safe screenshot or console error.
  • Status-page condition when it happened.
  • Use the feedback intake template.
  • Follow the two-week pilot plan before expanding testers.
