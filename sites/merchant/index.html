Merchant onboarding checklist
  1. Choose a receiving address from Wallet.
  2. Create a test invoice and open it in Pay.
  3. Try POS mode for an in-person checkout.
  4. Add a webhook URL only after your server verifies HMAC signatures.
  5. Export a CSV report for bookkeeping.
