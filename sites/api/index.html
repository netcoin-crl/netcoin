Reliability tools

  • Use /health or /status-lite for fast node checks.
  • Use mempool-info --summary to inspect pending transaction load.
  • Operators can clear only unconfirmed mempool transactions with mempool-clear.
  • Wallet sends now pre-check spendable balance, input count, and transaction weight.

Large-send safety

Send smaller test amounts first. Oversized transactions are rejected before broadcast so they do not make wallet, explorer, or mining feel stuck.

Builder platform

App-layer builders can prototype invoices, receipts, community posts, bounties, token records, webhooks, payout plans, and validation checks without changing consensus.

  • Use API keys for write routes.
  • Keep payout signing manual.
  • Treat Markets/Labs as testnet-only demos.

Webhooks

Merchant webhooks use HMAC signatures. Keep webhook secrets private and rotate them if exposed.
