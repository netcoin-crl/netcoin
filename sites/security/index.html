Security is the product.

Wallets and networks are only useful when users can trust the software, releases, and operational model. This page summarizes NetCoin's safety posture and links to public security docs.

Wallet safety

  • Private keys never leave the browser.
  • Wallet profiles are encrypted locally.
  • HTTPS is required for browser crypto.
  • Never paste a seed phrase into community pages.

Operator safety

  • No public admin site by default.
  • Payouts should use operator review and manual signing.
  • Release files should use checksums and signatures.
  • Write endpoints need rate limits and audit logs.

Security roadmap

  • External wallet and consensus review.
  • Security headers and CSP hardening.
  • Dependency audits and secret scanning.
  • Bug bounty and responsible disclosure.

NetCoin Security is a standalone site in the NetCoin ecosystem.
