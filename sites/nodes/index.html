Reliability tools

  • Use /health or /status-lite for fast node checks.
  • Use mempool-info --summary to inspect pending transaction load.
  • Operators can clear only unconfirmed mempool transactions with mempool-clear.
  • Wallet sends now pre-check spendable balance, input count, and transaction weight.

Large-send safety

Send smaller test amounts first. Oversized transactions are rejected before broadcast so they do not make wallet, explorer, or mining feel stuck.

Node vs seed

A node validates and relays chain data. A seed is a public node that helps new nodes find the network. A miner is a node that tries to produce blocks.

Public seed checklist

  • Run current NetCoin software.
  • Keep TCP port 28444 reachable.
  • Monitor uptime, peers, and block height.
  • Never expose private keys or wallet secrets.

Mining

Testnet mining helps validate blocks and test difficulty rules. It has no real-money value.

Run a public seed

sh tools/install_public_node.sh --dry-run
sh tools/install_public_node.sh --prefix "$HOME/.netcoin-public-node" --advertise YOUR_PUBLIC_IP_OR_DOMAIN:28444 --bandwidth-mode home

Open/forward port 28444 and test from outside your home network. M3 requires independent operators, not only founder AWS seeds.

Mine through public API

python -m netcoin miner --node http://18.220.89.128/api --wallet my-wallet.json --blocks 1 --sync-after

Use this no-tunnel URL when your network blocks api.netcoin.online or port 28444.

Local wallet node URL

python -m netcoin web --node http://18.220.89.128/api --faucet https://faucet.netcoin.online
