Node vs seed

RoleMeaning
NodeRuns NetCoin, validates chain data, relays network information, and may mine.
SeedA public reachable node listed so new nodes can find the network.
MinerA node that attempts to produce blocks.

Public seed checklist

  • Run 24/7 or close to it.
  • Keep TCP port 28444 reachable.
  • Run current software.
  • Monitor height and uptime.
  • Never expose wallet/private keys.
