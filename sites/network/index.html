Node vs seed

A node validates and relays chain data. A seed is a public node that helps new nodes find the network. A miner is a node that tries to produce blocks.

Public seed checklist

  • Run current NetCoin software.
  • Keep TCP port 28444 reachable.
  • Monitor uptime, peers, block height, and version skew.
  • Enable NETCOIN_FAST_CRYPTO=1 when serving large wallet transactions.
  • Never expose private keys or wallet secrets.

Mining

Testnet mining helps validate blocks and test difficulty rules. It has no real-money value.
