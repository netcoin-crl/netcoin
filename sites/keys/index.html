NetCoin release keys

This page is the public placeholder for NetCoin release verification keys. It documents the expected minisign and cosign surfaces without embedding private material.

minisign

Status: key ceremony required before operational M2. Publish the public key here only after the key is generated offline and backed up.

NETCOIN_MINISIGN_PUBLIC_KEY=not-yet-generated

cosign

Status: keyless or key-backed cosign policy must be chosen before public releases. Do not claim signed releases until artifacts verify against this page.

NETCOIN_COSIGN_IDENTITY=not-yet-configured

Verification flow

  1. Download release artifact, SBOM, provenance, and signature.
  2. Run python3 tools/verify_release.py ....
  3. Confirm the public key or identity matches this page.
