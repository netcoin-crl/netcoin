Phase 0 product architecture

Manage NET, verify the chain, download releases, and use markets from one focused hub.

Core tools are Explorer, Download, Home, Markets, and Wallet, always visible. Network, Build, and Ecosystem are tabs that open their own row of related tools when clicked.

Search Explorer Download Browse Markets Open Wallet

Start in 4 steps

  1. Create or import a wallet.
  2. Back it up before using larger balances.
  3. Claim faucet NET and send a test payment.
  4. Verify the transaction in Explorer.
ExplorerSearch addresses, transactions, blocks, mempool, and active-chain status. DownloadInstall files and release verification links for local testnet users. MarketsUse play-money prediction markets with wallet and portfolio context. WalletSend, receive, label activity, manage contacts, and protect backups.

Product rule

Every new NetCoin capability must improve an existing workflow, remove a hard ceiling, increase trust/safety/clarity, or reduce complexity. If it does not, it should not be added yet.
