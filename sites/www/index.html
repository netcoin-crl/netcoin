The simple NetCoin home.

Start combines the basic user, payment, and community paths in one place. Use Wallet for keys, Faucet for test coins, Pay for payment links, Community for coordination, and Explorer to verify what happened.

Open walletGet test coinsVerify in Explorer

First five minutes

  1. Create or unlock a wallet.
  2. Save the seed phrase somewhere offline.
  3. Request faucet coins.
  4. Send a small test payment.
  5. Paste the txid or address into Explorer.
WalletNon-custodial browser wallet for receiving, sending, contacts, activity, and local profiles. FaucetRequest public-testnet NET. Faucet coins have no real-money value. ExplorerSearch addresses, transactions, blocks, mempool, peers, and fee estimates. DownloadInstall from GitHub, launch a local wallet, run a node, or mine from your own hardware.

Pay basics

For normal users, Pay is just a payment link: address, amount, memo, and receipt. Merchants who need invoices, API keys, webhooks, refunds, or reports should use Merchant.

Community basics

Use Community for public discussion, questions, ideas, bounties, and contributor coordination. Use Governance only when an idea needs a formal proposal or vote.

Security baseline

NetCoin is educational public-testnet software. Never share a private key or seed phrase. Verify downloads, keep admin tools private, and treat self-hosted services as test systems.

Security center

NetCoin Start is the beginner/basic hub. Advanced areas stay separate so the simple path stays readable.
