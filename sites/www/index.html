Start in 4 steps

  1. Create or import a wallet.
  2. Back it up before using larger balances.
  3. Claim faucet NET and send a test payment.
  4. Verify the transaction in Explorer.
WalletSend, receive, label activity, manage contacts, and protect backups. ExplorerSearch addresses, transactions, blocks, mempool, and active-chain status. MarketsUse play-money prediction markets with wallet and portfolio context.

Product rule

Every new NetCoin capability must improve an existing workflow, remove a hard ceiling, increase trust/safety/clarity, or reduce complexity. If it does not, it should not be added yet.
