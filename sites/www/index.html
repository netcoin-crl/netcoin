Launch path

  1. Create or restore a wallet.
  2. Request public-testnet coins from the faucet.
  3. Send a small payment and verify it in Explorer.
  4. Install locally when you are ready to mine or run a node.
  5. Use Settings or ?mode=developer to reorder tools for your role.
WalletNon-custodial browser wallet with contacts, activity, fee controls, coin status, and mining helpers. PaySimple payment requests and receipt flows for public-testnet transactions. ExplorerLive blocks, transactions, addresses, mempool, token views, and public network state. FaucetPublic-testnet NET for onboarding, demos, wallet testing, and transaction checks. Learn & DownloadBeginner setup, Mac/Windows/Linux commands, public mining, node checks, and release safety. CommunityQuestions, ideas, bounties, contributor coordination, and public discussion.

Interface profiles

Modes are no longer visible page switches. Use Settings in the top navigation, or append ?mode=merchant, ?mode=developer, ?mode=operator, ?mode=governance, or ?mode=labs to reorder the Directory.
