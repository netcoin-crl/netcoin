Status is part of Network.

NetCoin groups service status, seed versions, peer health, mining signals, and node-operator checks in one Network hub.

Open Network hubOpen Explorer

Operator quick check

python tools/check_public_network.py
curl https://api.netcoin.online/api/health
curl https://api.netcoin.online/api/info

What to check

  • All seeds answer /health.
  • Versions match the latest GitHub deployment.
  • Heights and tip hashes agree.
  • Peer counts are non-zero and stable.
  • Fast crypto is enabled where large sends are expected.

Where to look

Use Network for node health, Explorer for blocks and transactions, Security for release verification, and Developers for API details.

This status subdomain stays online for old links, but the active status experience is Network.
