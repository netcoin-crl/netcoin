# NIP-0005: Upgrade-activation standard (height-gated, no chain reset)

| | |
|---|---|
| NIP | 0005 |
| Title | Upgrade-activation standard |
| Status | Active |
| Created | 2026-07-03 |

## Rule

Every consensus change ships **activation-gated by block height** and **never
resets the chain** (see `docs/UPGRADE_POLICY.md`):

1. Pick an activation height `A` comfortably above the current public tip so
   node operators and miners can upgrade first. If the change interacts with
   difficulty retargeting, `A` must be a multiple of
   `DIFFICULTY_ADJUSTMENT_INTERVAL` so no adjustment window mixes rule sets in
   an unbounded way.
2. Below `A`, the old rules apply byte-for-byte, so every historical block
   stays valid and a fresh sync reproduces the same chain.
3. The parameter and gate live in `netcoin/params.py` as
   `<FEATURE>_ACTIVATION_HEIGHT` plus a height-aware accessor, with tests
   asserting the boundary (`A-1` old rules, `A` new rules) and asserting the
   live chain's historical heights keep the original rules.
4. **Miners must be on the release before height `A`** or their blocks are
   rejected by upgraded nodes and they fork themselves off.

## Activations on the public testnet

| Height | Change | Release |
|---|---|---|
| 1,000 | Legacy random-emission window opens (later closed at 4,200) | 0.7.x |
| 4,200 | Deterministic reward schedule: 50 NET × (9/10)^⌊h/265,000⌋ | 0.7.x |
| **5,010** | **Spacing v2: 5-minute target blocks** (`TARGET_SPACING_V2_SECONDS = 300`; retarget timespan and the lone-miner floor gap follow) | 0.9.0 (height moved to 5,010 in 0.10.1) |

## Spacing v2 notes (height 5,010)

- `target_spacing_at(h)` returns 120s below 5,010 and 300s at/after it. (Originally scheduled for 6,000 in v0.9.0; moved earlier to 5,010 in v0.10.1 (nearest retarget boundary to the requested 5,000) while the chain was at ~4,745 and every public seed was upgraded in the same rollout.)
- 5,010 is a retarget boundary; the single window that straddles the transition
  is bounded by the standard ×4/÷4 timespan clamp, and the lone-miner floor
  rule prevents a stall if difficulty briefly overshoots.
- The emission schedule is defined in **blocks**, not time: 5-minute blocks
  slow real-time emission by 2.5× but do not change per-block subsidies or the
  265,000-block reduction epochs.
