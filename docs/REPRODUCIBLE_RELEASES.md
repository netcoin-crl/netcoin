# Reproducible Releases and Verification

## Build

Preferred release build:

```bash
tools/make_release.sh v0.12.0
```

This creates a source archive and `SHA256SUMS`. If GPG is configured, it also writes `SHA256SUMS.asc`.

## Verify

```bash
python tools/verify_release.py dist/
```

The verifier checks every listed file hash and verifies the detached GPG
signature when present.

Official GitHub tag releases also include Sigstore keyless bundles generated by
the release workflow with GitHub Actions OIDC. To require those bundles, pin the
expected workflow identity:

```bash
python tools/verify_release.py dist/ \
  --require-keyless \
  --certificate-identity https://github.com/OWNER/REPO/.github/workflows/release.yml@refs/tags/vX.Y.Z
```

The OIDC issuer defaults to `https://token.actions.githubusercontent.com`.
Keyless bundles are named `<artifact>.sigstore.json` and are expected for the
source archive, `netcoin-sbom.json`, and `SHA256SUMS`.

Official GitHub tag releases also publish GitHub artifact attestations for the
source archive, `netcoin-sbom.json`, and `SHA256SUMS`. These attestations bind
each subject digest to GitHub-hosted SLSA build provenance for the release
workflow.

Generate verification commands for downloaded artifacts:

```bash
python tools/plan_release_attestation_verification.py dist/ --repository OWNER/REPO
```

Then run the printed commands, for example:

```bash
gh attestation verify dist/netcoin-X.Y.Z.zip -R OWNER/REPO
gh attestation verify dist/netcoin-sbom.json -R OWNER/REPO
gh attestation verify dist/SHA256SUMS -R OWNER/REPO
```

Attestation verification is an online GitHub CLI check. It complements local
checksum, optional GPG, and Sigstore bundle verification; it does not replace
the local checksum check.

## Manifest and SBOM

Generate a JSON release manifest with file hashes and dependency metadata:

```bash
python tools/professional_readiness.py --manifest dist/netcoin-release-manifest.json
```

## Release Checklist

- Version matches `pyproject.toml`, README, and release notes.
- Full test suite passes or documented exceptions exist.
- Professional readiness checker is clean or open items are explicitly accepted.
- Archive checksum is published.
- Sigstore keyless bundles are published for official GitHub releases.
- GitHub artifact attestations verify for the release archive, SBOM, and
  checksum file.
- GPG signature is published when the offline signing key is available.
- Security advisory review is complete.
