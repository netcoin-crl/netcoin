# M5 — Mainnet Launch Plan

## Goal

Launch mainnet without chaos.

## Preconditions

- M4 strict complete.
- External audit complete.
- Genesis distribution approved.
- Signed binaries ready.
- Independent operators ready.
- Mining pools ready.
- Public communication ready.

## Launch windows

### T-4 weeks

- Feature freeze.
- Final testnet soak.
- Distribution manifest frozen.

### T-3 weeks

- Public announcement.
- Risk disclosures.
- Genesis config published.

### T-2 weeks

- Third-party genesis review.

### T-1 week

- Signed binaries.
- Testnet frozen.
- Mining pool notification.
- On-call schedule ready.

### T-0

- Genesis ceremony.
- Independent witnesses confirm hash.
- Public launch log.

### T+1 day

- 100+ blocks.
- 5+ independent miners.

### T+7 days

- Independent state confirmation.

### T+30 days

- No unplanned hard fork.
- Public post-launch report.
