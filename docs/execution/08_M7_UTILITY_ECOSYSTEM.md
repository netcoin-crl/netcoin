# M7 — Utility and Ecosystem Plan

## Goal

NetCoin has usage beyond speculation.

## Recommended positioning

The strongest near-term utility path is:

```text
Developer-first Bitcoin-family sandbox
```

Reason:

- NetCoin already has wallet, faucet, explorer, API, docs, testnet, CI, Rust/Python/TS foundations.
- This avoids competing directly with BTC/LTC/Lightning/USDC on payments too early.
- It turns the existing infrastructure into the product.

## Workstreams

### M7.1 SDK distribution

- npm package.

- Examples.

### M7.2 Developer sandbox

- Quickstart.
- Faucet.
- Wallet.
- Explorer.
- API keys.
- Sample app templates.
- CI-friendly local network.

### M7.3 Grants tracker

- Public application page.
- Scoring rubric.
- Award history.
- Milestone proof.

### M7.4 Ecosystem metrics

Track:

- weekly active addresses,
- non-airdrop tx count,
- faucet-to-wallet completion rate,
- SDK downloads,
- third-party repos,
- grants completed.
