# NetCoin Execution Plan Skeleton

This package is an additive planning structure for taking NetCoin from the current clean source baseline into real operational completion across M1–M7.

It does not modify consensus, emission, genesis, address format, seed deployments, or secrets. It is meant to be copied into the repo or Obsidian vault and expanded over time.

Recommended repo location:

```text
docs/execution/
```

Recommended vault location:

```text
NetCoin/Execution/
```

Core rule:

```text
Source-complete is not operationally complete.
Each milestone closes only when its evidence files are real, reviewed, and linked from the milestone status page.
```
