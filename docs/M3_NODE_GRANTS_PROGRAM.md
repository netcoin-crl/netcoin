# M3 Node Grants Program

Draft only. Do not promise mainnet value until governance approves conversion terms.

## Purpose

Recruit independent testnet node operators and miners for M3 decentralization.

## Draft reward bands

- 500 testnet NET: 7 days uptime, reachable port, valid status samples.
- 1,000 testnet NET: 30 days uptime with peer diversity and incident reporting.
- 2,000 testnet NET: independent mining evidence or seed-DNS operation.

## Eligibility

- Must not be a founder-controlled machine.
- Must provide endpoint and basic operator contact.
- Must avoid fake/self-dealing operators.
- Must agree that testnet rewards have no current real-money value.

## Mainnet conversion warning

Any 1:1 conversion promise needs explicit public governance approval before mainnet. Until then, this document is a pilot incentive draft only.
